# ENVS: Environment-Native Verified Search for Long-Horizon GUI Agents

Trajectory discovery remains a central bottleneck for GUI agents operating in desktop environments, since successful executions are sparse, long-horizon, and costly to obtain at scale. Existing online reinforcement learning approaches are constrained by current-policy rollouts and limited exploration of the success landscape. We propose an environment-driven search-and-filter pipeline for OSWorld GUI agents that separates trajectory discovery from policy optimization. Our method searches in live desktop VMs by branching only when sampled actions induce distinct executable GUI behaviors. We then evaluate trajectory leaves with the OSWorld oracle and convert successful leaves into globally balanced step-level supervision. This transforms sparse terminal feedback into dense action-level training targets, while allowing dataset-level gradient control.

We evaluate on standard OSWorld and introduce **OSWorld-Noisy**, a held-out perturbation setting with recoverable desktop interruptions. Across completed experiments, search-filtered supervision outperforms ARPO-style online policy optimization on both clean and noisy evaluation with substantially lower GPU cost. Noisy trajectory collection does not improve OSWorld task completion compared with clean search data at the same data budget. However, auxiliary evaluations suggest that perturbations help the model retain broader visual and reasoning abilities. Together, these results suggest that GUI environments are not only benchmarks, but also native sources of supervision: they can be used to discover, verify, and diversify the trajectories agents learn from.
